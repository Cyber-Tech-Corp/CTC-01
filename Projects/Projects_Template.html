NetGuard SIEM

Statut: Active
Durée: 6 mois
Rôle: Lead Architecte Sécurité
Équipe: 3 personnes
Python ELK Stack Docker Suricata Grafana Ansible

//Description

NetGuard SIEM est une plateforme complète de Security Information and Event Management (SIEM) conçue pour les petites et moyennes infrastructures. Elle permet de centraliser les logs de sécurité, détecter les anomalies en temps réel, et générer des alertes automatisées pour les équipes SOC.

Le système repose sur une architecture modulaire basée sur la stack ELK (Elasticsearch, Logstash, Kibana) enrichie de règles Suricata personnalisées et d'un moteur d'analyse comportementale développé en Python.

//Objectifs

  • Centraliser les logs de multiples sources (firewalls, serveurs, endpoints)
  • Détecter les tentatives d'intrusion et comportements anormaux en temps réel
  • Automatiser la réponse aux incidents de sécurité courants
  • Fournir des dashboards interactifs pour le monitoring et le reporting
  • Assurer la conformité avec les standards de sécurité (ISO 27001, RGPD)

//Architecture Technique

L'architecture suit un modèle microservices conteneurisé avec Docker Compose, permettant une scalabilité horizontale et un déploiement rapide :

# docker-compose.yml - Stack NetGuard SIEM version: '3.8' services: elasticsearch: image: elasticsearch:8.11.0 environment: - discovery.type=single-node - xpack.security.enabled=true volumes: - es_data:/usr/share/elasticsearch/data ports: - "9200:9200" logstash: image: logstash:8.11.0 volumes: - ./logstash/pipeline:/usr/share/logstash/pipeline - ./logstash/config:/usr/share/logstash/config depends_on: - elasticsearch kibana: image: kibana:8.11.0 ports: - "5601:5601" depends_on: - elasticsearch suricata: build: ./suricata network_mode: host cap_add: - NET_ADMIN - SYS_NICE netguard-engine: build: ./engine environment: - ELASTICSEARCH_URL=http://elasticsearch:9200 - ALERT_WEBHOOK=${WEBHOOK_URL} depends_on: - elasticsearch

//Fonctionnalités Clés

  • Collecte multi-sources : Ingestion de logs via Syslog, Beats, et API REST personnalisée
  • Détection IDS/IPS : Règles Suricata personnalisées avec plus de 200 signatures
  • Analyse comportementale : Moteur ML pour la détection d'anomalies réseau
  • Alerting automatisé : Notifications via Slack, email, et webhooks
  • Dashboard temps réel : Visualisation Kibana avec cartes de menaces géolocalisées
  • Rapports de conformité : Génération automatique de rapports ISO 27001

💻 Exemple de Code

Extrait du moteur de détection d'anomalies :

# engine/detector.py - Anomaly Detection Engine import numpy as np from elasticsearch import Elasticsearch from datetime import datetime, timedelta class AnomalyDetector: def __init__(self, es_url, threshold=2.5): self.es = Elasticsearch([es_url]) self.threshold = threshold self.baseline = {} def compute_baseline(self, index, field, hours=24): """Compute statistical baseline for a given field.""" query = { "range": { "@timestamp": { "gte": f"now-{hours}h", "lte": "now" } } } agg = { "stats": {"field": field}, "percentiles": {"field": field, "percents": [95, 99]} } result = self.es.search( index=index, query=query, aggs={"field_stats": agg}, size=0 ) stats = result["aggregations"]["field_stats"] self.baseline[field] = { "mean": stats["stats"]["avg"], "std": stats["stats"]["std_deviation"], "p95": stats["percentiles"]["values"]["95.0"] } return self.baseline[field] def detect(self, field, current_value): """Detect if current value is anomalous.""" if field not in self.baseline: return False, 0 b = self.baseline[field] z_score = abs(current_value - b["mean"]) / b["std"] return z_score > self.threshold, round(z_score, 2)

//Résultats

  • Réduction de 73% du temps moyen de détection d'incidents (MTTD)
  • Traitement de plus de 50 000 événements/minute en production
  • Taux de faux positifs réduit à moins de 2% grâce au ML
  • Déploiement automatisé en moins de 15 minutes via Ansible
